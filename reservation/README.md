# 체육관 무대 · 무용실 예약 시스템

구글 스프레드시트 + Apps Script 웹앱. 비용 없음, 서버 불필요.

## 규칙
- 매주 **수요일 08:00**에 **다음 주 월~금** 전체가 열림 (이미 열린 이번 주도 계속 예약 가능)
- 한 칸 1시간
- **한 주(월~금) 최대 2칸** (학번 기준, 이번 주·다음 주 각각 계산)
- **사용 당일 08:00 이후**에는 한 주 제한이 풀려 남은 빈 칸을 추가 예약 가능
- 지난 시간은 예약 불가, 동시에 눌러도 한 명만 예약됨(LockService)
- 예약할 때 **사용 주의사항을 보여주고 체크해야** 예약됨 (동의 기록은 `예약` 시트 G열). 문구는 `CONFIG.notices`에서 수정 (`common`=모두, `rooms`=해당 장소 예약자에게만)
- 취소는 예약 때 쓴 학번+이름이 같아야 가능

## 가장 쉬운 설치: 파일 1개 (PC 권장)
1. `script.google.com` 접속 → **새 프로젝트**
2. 기본 `Code.gs` 내용을 모두 지우고 **`올인원_Code.gs`** 내용 전체를 붙여넣기 → 저장
3. **배포 → 새 배포 → 유형: 웹 앱** (실행 사용자: 나 / 액세스: 모든 사용자) → 배포 → 권한 승인(고급 → 이동)
4. 나온 **웹 앱 URL**을 공유. 처음 접속하면 내 드라이브에 `시설 예약 (체육관 무대·무용실)` 시트가 자동 생성됨
5. 화면(HTML)까지 한 파일에 들어 있어 `Index.html`, `appsscript.json` 은 필요 없습니다.

※ `Code.gs`/`Index.html` 을 수정했다면 `python3 build_single.py` 로 `올인원_Code.gs` 를 다시 만드세요.

## 날짜·시간 차단 (학교 행사, 시험 등)
`차단` 시트(처음 접속 때 자동 생성)에 행을 추가하면 그 시간은 예약 화면에서 "🚫 사용 불가"로 표시되고 예약되지 않습니다. 행을 지우면 다시 열립니다.

| 시작날짜 | 종료날짜(선택) | 시간(선택) | 장소(선택) | 사유(선택) |
|---|---|---|---|---|
| 2026-12-01 | | | | 학교 행사 |
| 2026-12-07 | 2026-12-11 | | 무용실 | 기말고사 |
| 2026-12-03 | | 15:00 | 체육관 무대 | 방송 점검 |

- 종료날짜를 비우면 하루만, 시간을 비우면 그날 전체, 장소를 비우면 두 곳 모두 막힙니다.
- 날짜는 `yyyy-mm-dd`, 시간은 `12:00`, `15:00` 형식입니다.
- 이미 들어 있는 예약은 자동으로 지워지지 않으니 `예약` 시트에서 직접 지우세요.

## 설치 (파일 3개 방식)
1. 새 구글 스프레드시트를 만든다.
2. 메뉴 **확장 프로그램 → Apps Script**
3. `Code.gs` 내용을 붙여넣고, **파일 추가 → HTML** 로 `Index` 파일을 만들어 `Index.html` 내용을 붙여넣는다.
4. 왼쪽 ⚙ **프로젝트 설정 → "appsscript.json 매니페스트 파일 표시"** 체크 후 `appsscript.json` 내용을 붙여넣는다. (시간대 Asia/Seoul)
5. **배포 → 새 배포 → 유형: 웹 앱**, 실행 사용자 `나`, 액세스 `모든 사용자` → 배포 후 나온 URL을 학생·교사에게 공유.
6. 처음 접속 시 권한 승인을 한다. `예약` 시트는 자동 생성된다.

코드를 고친 뒤에는 **배포 관리 → 수정 → 새 버전**으로 다시 배포해야 반영된다.

## 시간 설정 변경
`Code.gs` 맨 위 `CONFIG`:
- `slotsByDow`: 요일별 칸 시작 시각 (기본: 월~금 점심 12~13시, 월·목·금은 15~16시 추가)
- `blockMinutes`: 한 칸 길이(분, 기본 60)
- `rooms`, `maxPerWeek`, `openWeekday`, `openTime`, `releaseTime`

## 관리
- `예약` 시트에서 행을 지우면 예약이 취소된다. 학번·이름 전체를 확인할 수 있다.
- 화면에는 학번 뒷 2자리와 이름만 노출된다.

## 스프레드시트 없이 설치 (휴대폰 크롬 가능)
1. 크롬에서 `script.google.com` 접속 → ⋮ 메뉴 → **데스크톱 사이트** 체크 → **새 프로젝트**
2. `Code.gs`, `Index`(HTML), `appsscript.json` 을 위와 같이 붙여넣기
3. 배포 → 웹 앱 (실행: 나, 액세스: 모든 사용자)
4. 첫 예약 화면을 열면 내 드라이브에 `시설 예약 (체육관 무대·무용실)` 시트가 자동으로 만들어집니다.
